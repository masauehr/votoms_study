# votoms_study — 装甲騎兵ボトムズ 深掘り分析

詳しくは [votoms_study.md](votoms_study.md) を参照。

アニメ『装甲騎兵ボトムズ』シリーズの全体像を、作品ごと・テーマごとに整理して深掘りする分析プロジェクト。
コードではなく、**読み物（Markdown）中心**。

## 目的
- シリーズ全体（TV・OVA・劇場版・外伝）の時系列と作品間の関係を明らかにする
- 登場人物・組織・設定（百年戦争、異能生存体、パーフェクトソルジャー等）を整理する
- 各作品が「誰の物語か」を、一次情報にあたって確認しながら考察する

## 方針
- 事実と考察を分けて書く。出典のない記述は「未確認」と明記する
- 検索要約などの二次情報は鵜呑みにせず、本編・公式・信頼できる資料で裏取りする
- 画像・映像・脚本の転載はしない（引用は最小限）
