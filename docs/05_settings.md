## 1. 異能生存体と異能者は別の語（重要）

| 語 | 内容（◎） | 出典 |
|---|---|---|
| 異能生存体 | ペールゼンが命名した、生存率が桁違いに高い個体の呼称。人類での発生確率は二百五十億分の一で、キリコが該当（公式） | 公式KEYWORDS／Wikipedia（ペールゼンの脚注） |
| 異能者 | 暦4000年頃にクエント人の間に生まれた突然変異種。コンピュータへの適応性が異常に高く、肉体の代謝能力も高い。ワイズマンの出自 | Wikipedia 用語節「異能者」 |

- Wikipedia の用語節に「異能生存体」の見出しはなく、見出しは「異能者」。
- 作品内では、第48話で神（ワイズマン）が語る「生まれながらのPS・異能者」が、キリコの出自にあたる（02参照）。
- 一方、ペールゼン・ファイルズ記事によると、ペールゼンのファイルに載った5人は経歴に共通点がなく、共通点は戦場での生存率の高さだけだった。ウォッカムはそこから「異能生存体」「不死の兵士」と見なした。
  ペールゼンは後に、ファイルは偽物で、**キリコ以外は異能生存体ではない**と明かす。
- 考: 「異能生存体」はペールゼン側（軍・観察）の語で、「異能者」はクエント側（出自・起源）の語。キリコは両方に該当するとされる（Wikipedia キリコの項:「生まれながらの孤高の異能者」「ワイズマンの後継者」）。

## 2. パーフェクトソルジャー（PS）

◎ Wikipedia「パーフェクトソルジャー」
- 人体を改造した架空の強化人間兵器。「PS」と略され、「完全なる兵士」とも呼ばれる。
- 人体にマイクロコンピューターと一体化する思考・判断力を加え、筋力を強化。その状態を「素体」と呼ぶ。脳にも手を加えられた。
- 欠点: 寿命は「僅か2年」。能力維持と生命維持に、高価なヂヂリウムを大量に消費する。

◎ Wikipedia「装甲騎兵ボトムズ」用語節
- 戦場で理想的な能力を発揮できるよう、肉体や脳神経に人為的な処置を施した一種のサイボーグ。メルキア軍で開発され、秘密結社に奪取されて研究が進んだ。寿命は2年程度で、ヂヂリウムの定期的な照射が必要。バララント側でも同様に開発された。

◎ 公式 KEYWORDS
- 「遺伝子操作により、筋力や反射神経を強化した完璧なる兵士」。TVシリーズではフィアナとイプシロンがこれにあたる。

### 食い違い
- 改造方法の記述が、Wikipedia（マイクロコンピューター・脳神経の処置、サイボーグ）と公式（遺伝子操作）で異なる。
- Wikipedia の PS 記事には出典不足の注記がある。
- 「PSの寿命は2年」は、後のOVA『赫奕たる異端』制作時に付け加えられた設定とWikipediaは述べる（00参照）。TV本編の設定として扱うのは避ける。

### 素体・プロトワン・イプシロン（◎）
- 素体（素体=プログラムのみの状態）: 公式によると、リドでキリコが目撃した素体が、秘密結社に奪われてプロトワン（フィアナ）になった。
- プロトワン: PS第1号、通称「プロト・ワン」。リドの研究施設で見つかった眠れる女性。キリコが後に「フィアナ」と命名（Wikipedia PS記事）。
  Wikipedia の登場人物節では、「フィアナ」はウドの人々の呼称で、軍や組織は「プロト・ワン」「素体」と呼ぶとある。
  名の由来は「火」「炎」（Fire）の女性形とされる。
- イプシロン: 秘密結社が創った第2のPS「プロト・ツー」。プロト・ワンを元に作られ、搭乗機は「ブルーAT」。サンサの決闘でキリコに敗れて死ぬ。
- Wikipedia PS記事: プロト・ワンは、キリコへの依存から秘密結社に欠陥品とされ、キリコと行動を共にした。

## 3. ヂヂリウム（◎）

- 半液体化金属の半導体。半透明の青い物質。常温で超伝導効果を持つため、ATなどに載せる高速コンピューター回路に不可欠（Wikipedia 用語節）。
- 放射線を発し、第3次銀河大戦末期には最重要の戦略物資（同）。
- 非常に高価な戦略物資で、PSの身体機能維持に必要不可欠。気化すると青い燐光を発する（公式）。
- PSにとっては生命線。浴びると本来の能力を発揮し、なければ動作が鈍り、硬直して死に至る（Wikipedia PS記事）。
- 表記は「ジジリウム」等の揺れがあったが、データベース作成時に高橋監督の判断で「ヂヂリウム」に統一（Wikipedia 用語節）。

物語との対応（TV第6・7・35〜36話）: キリコとフィアナの出会いの場がヂヂリウム保管庫（第6話）、フィアナがヂヂリウム欠乏で全身硬直を起こす（第35話）。

## 4. ワイズマンとクエント

### ワイズマン（◎ Wikipedia 用語節・公式）
- かつてクエント星を追放された異能者たちが、クエントに帰還後、地底深くの原形質保存装置に自らの意志を集合させ、意識集合体となったときの名称。
- 肉体を失って以後、古代クエント文明の科学力を背景に1000年以上にわたり銀河の文明に干渉し、歴史を影から操ってきた。自らを神と信じ、人類からは存在を知られていない。
- 公式: 秘密結社はワイズマンを神と崇めた。異能者は意思と記憶を原形質保存装置に残し、文明を裏から操作し続けた。
- 関連（Wikipedia PS記事）: ネクスタントが「ワイズマンに補助脳を乗っ取られた」とある。

これにより、第52話で壊されるものが「原形質保存装置」（02参照）であることと、設定上の「ワイズマン＝異能者の意識集合体」が一致する。

### クエント（◎）
- 銀河のほぼ中心部。超古代文明が栄えたが、暦4000年頃に崩壊し、7210年代には砂漠に覆われる（Wikipedia）。
- 公式: 古代クエント文明は三千年前の超文明で、異能者の出現により自ら放棄した。
- 住民は深い谷底で原始的な生活を送る。主産業はクエント素子の採掘と、成年男性の傭兵派遣。首都はゴモル（住民のほとんどは他星の人間）。
- 第43話の長老メジが語る「3000年前に現れ追放された神」の伝説（02）と、公式の「三千年前」が対応する。

## 5. 暦・戦争・不可侵宙域（◎ Wikipedia 用語節）

- 百年戦争（第3次銀河大戦の俗称）: アストラギウス暦7113〜7213年。TV本編に「第3次銀河大戦」の名は出ず、「百年戦争」と呼ばれる。
- アストラギウス暦: 惑星ジアゴノで神の啓示が書かれた「ヤーダル碑」を発見した時を紀元とする統一暦。ギルガメス暦元年は4871年、バララント暦元年は4153年に当たる。
- 不可侵宙域: ギルガメスとバララント両勢力の立ち入りを禁止する中立宙域。
  7213年の休戦条約で、サンサ星周辺など、終戦時に支配が明確でない宙域が指定された。代表はクエント星、アンティティーツ星（最大の銀行がある）。
- 「アストラギウス歴」の誤表記は、『赫奕たる異端』で「暦」に直された。
- ギルガメス暦・バララント暦に独立の定義項目はない（換算のみ）。

→ 00 の△（暦）は、この原文確認で◎になった。

## 6. レッドショルダー・ペールゼン（◎）

- 正式名称は「第24メルキア方面軍機甲兵団 特殊任務班X-1」（TVの人物節は「戦略機甲兵団」と表記）。ATの右肩を血の赤に染めていたことが由来で、「吸血部隊」と俗称される。
- ヨラン・ペールゼン: 部隊の創設者。百年戦争当時は大佐、終戦時は少将。「異能生存体」の命名者。

## 7. この整理から見えたこと（考）

1. 「PS」と「異能者」は、別の系統として設定されている。PSは人工（軍・秘密結社）、異能者は天然（クエントの突然変異）。キリコは天然の側で、フィアナ・イプシロンは人工の側。
2. 第39話でフィアナが叫ぶ「あなたもPS」は、人工のPSと同じくらい常人離れしているという意味だった可能性があり、第48話で神がそれを訂正する形になる。紹介文だけでは確定できない。
3. 第48話の神の言葉「生まれながらのPS」は、天然の異能者のことを、人工のPSになぞらえた言い方に読める。
4. ペールゼン・ファイルズの結末（ファイルは偽物で、キリコだけが異能生存体）は、「軍が見つけたつもりの異能は、実は一人だけだった」という皮肉で、キリコの孤独を際立たせる。
