# OVA以降の深掘り：赫奕たる異端・孤影再び・幻影篇

> 出典は日本語版Wikipedia各作品ページ（原文取得）。TV本編から約30年後を描く3作品を扱う。
> ケース;アービン・灰色の魔女は、キリコ・フィアナが登場しないため対象外（00参照）。
> 確度: ◎=記事で確認、考=筆者の考察。

## 1. 制作の経緯（◎ 赫奕たる異端）

- 高橋良輔は、TV最終回のラストシーン以後は作らないという趣旨の発言をしていた。それでも続編を望む声があり、製作に踏み切った。高橋自身も、ノベライズのあとがきで「諸般の事情で製作に踏み切ってしまった」と書いている。
- 完成作には抗議が殺到した。特にヒロインのフィアナが力尽きる展開には、スタッフ内部からも批判が出た。出典は、LD最終巻ライナーでの高橋と今西隆志の対談（今西が「一部のスタッフから猛烈な抗議が出てますよ」と語った）。
- つまり、フィアナの死は「作者が最初から決めていた結末」ではなく、「終わらせたものを再開した結果の選択」だった。

## 2. 赫奕たる異端（1994〜95・全5話）

### あらすじ（◎）
- 暦7247年。キリコとフィアナが眠りについて32年。負傷兵用コールドカプセルの群れに、二人のカプセルが紛れ込む。
- 惑星マナウラ軌道の宇宙工場群コンプラントで蘇生処置。キリコは蘇生するが、フィアナは蘇生不良のまま連れ去られる。
- キリコはフィアナを追い、宗教結社マーティアルの権力闘争に巻き込まれる。
- フィアナの余命は、コールドスリープに入った時点でほぼ尽きていた。キリコは彼女と永遠に生きるため眠った、という説明がある。キリコが追うのは、再凍結して少しでも延命させたいから。
- フィアナは、何も知らないテイタニアに完全に蘇生される。迫る死を前に、自分亡き後のキリコをテイタニアに託す。キリコの腕の中で力尽きる。
- ロッチナに見送られ、再びカプセルに収められて宇宙を漂う。

### マーティアルとキリコの位置づけ（◎）
- マーティアルは、ギルガメス・バララント双方に信者を持つ巨大な宗教結社。前身は惑星ジアゴノの原始宗教。TV本編の秘密結社はマーティアルから分裂した組織。
- キリコは「かつて神を殺した男」。力を求めず服さないが異能に恵まれ、マーティアルの教義にとって都合の悪い存在とされた。
- 殺すこともできないため、「触れ得ざる者」と定義された（ソノバ議定書）。第5話のタイトルでもある。

### 考
- TVでは、フィアナの命は「ヂヂリウム」で保たれていた。OVAでは「寿命」が主題になる。ただし「PSの寿命2年」が記事に出るのは、**TV記事のキリコの項のみ**で、OVA3記事には記述がない（下記）。
- フィアナが最後に託す相手がテイタニア（キリコを付け狙っていた敵）であることは、キリコが一人になる未来を、彼女自身が最も恐れていたことを示す。

## 3. 孤影再び（2011・OVA）

### あらすじ（◎）
- 「アレギュウムの赫い霍乱」から3か月後。キリコは交易都市グルフェーへ向かう。目的は語らない。
- 小説版・記事の設定では、キリコの目的は、宇宙を漂う流星となったフィアナのカプセルを見るため（邪魔をする黒い稲妻旅団と戦う）。
- テイタニアは、キリコ抹殺の使命を果たせず粛清されそうな中、キリコのために身を投げうって助勢する。力尽きる。
  記事によると、テイタニアはキリコが流星のカプセルを追っていたと思っていたが、キリコはそれに目を向けず、死にゆくテイタニアを無言で抱いた。彼女は安息の中で息絶え、オアシスの花畑に葬られる。
- キリコは弔ったあと、黙って姿を消す。ゴウトが、キリコが無言で去った理由を「家族やグルフェーに迷惑がかからないように」と説く。

### 考
- フィアナのカプセルではなく、目の前のテイタニアを抱く場面が、キリコの変化を示す。喪失のあと、キリコは過去（フィアナ）だけを見ていない。
- 一方、グルフェーへ向かった目的（流星を見る）は、記事では小説版の設定として書かれている。アニメ版でどこまで明示されるかは未確認。

## 4. 幻影篇（2010・全6話）

### あらすじ（◎）
- 孤影再びの後。キリコは仲間に別れを告げず去り、サンサのゾフィーの屑鉄屋に住み込んで、ほぼ無償で働いていた。
- バートラー夫妻（バニラとココナ）は、銀婚式旅行でウド、クメン、サンサを巡り、キリコとの思い出をたどる。
- キリコは謎のATに襲われ、ヌルゲラントへ移送される。ヌルゲラントは、消滅したクエントの双子星。消滅直前にクエント人の多くが転送されて生き延びていた。
- そこでワイズマンと再会し、「神の子」の養育を託される。

### 「神は死んだ」の後（◎、本稿で最大の論点）
- 記事の用語項: ワイズマンは、クエント星の爆発の際、多くの民と共にヌルゲラントへ転移し、**自らの意思で甦った**。選ばれた「神の子」を胎内に抱え、養育者を求めている。
- TV第52話でロッチナは「神は死んだ、お前が殺した」と叫んだ。その結末が、幻影篇で覆される。
- ワイズマンはキリコを養育係に指名済みだった。法王モンテウェルズが後見人になろうとして拒まれ、絶望と怒りで銃を乱射し、全弾が跳弾となって自らを死に至らしめる。

### フィアナの扱い（◎）
- エンディングで眠るイメージのみ登場する。
- 第5話で、ワイズマンがキリコに過去の記憶を見せる精神攻撃の場面がある。そこでは、ヨラン・ペールゼンがサンサの実験施設をレッドショルダー部隊で襲撃した時に、キリコとフィアナが出会ったように見せかけられる。
  実際の出会いはリド（TV第1話）なので、これは「見せかけられた」偽の記憶。

### 考
- TV第52話で神を殺したのは、「後継者」（第48話）になることを拒み、神の座を壊す選択だった。幻影篇は、その神が別の形で残っていた、という続きにあたる。
- 「神の子」の養育は、キリコが「後継者」の座を継ぐのではなく、後継者を育てる側に回るということ。TV第51話の「力が欲しい」の答えとは、別の形で神に関わり直している。
- 幻影篇の記事は、「完結編とする情報が一部にあるが、公式サイトにはそうした記載はない」と書く。高橋は『孤影再び』のライナーで今後も続けたい旨を語り、2020年から連載小説『装甲騎兵ボトムズ チャイルド 神の子篇』が発表されている（◎）。

## 5. 食い違い・未確認

- **ロッチナの生死**: TV記事のロッチナの項は、TVシリーズと赫奕たる異端の間の「アンティテーツ事件」で死亡したと書く（◎）。しかし赫奕たる異端・幻影篇の記事では、ロッチナは存命で登場する（◎）。記事間の食い違いで、未解決。
- **ロッチナの肩書**: 赫奕たる異端では「元バララント宇宙軍将校」、幻影篇では「元バララント軍大佐」。
- **表記**: 「アレギウム」（赫奕たる異端）と「アレギュウム」（孤影再び・幻影篇）。
- **PSの寿命2年**: TV記事のキリコの項に、「後に赫奕たる異端制作時に付け加えられた」とある（出典の脚注なし）。同項は、TV第1話から最終話ラストまでで約2年が経過しており、この時点でほぼ寿命を迎えていたことになるとも書く（◎）。ただし、**OVA3記事には「寿命2年」の記述がない**。
- **ヂヂリウム**: OVA3記事のどこにも出ない。
- 孤影再びのアニメ版は、小説版と設定が異なる点が多い（テイタニアの最期、ロッチナ・クルトルの不登場など）。
