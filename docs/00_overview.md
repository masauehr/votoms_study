- 孤影再びの後に幻影篇が続く。

## 3. 基本設定

◎
- アストラギウス銀河を二分するギルガメスとバララントが100年続けた戦争が「百年戦争」。その末期が物語の始まり。
- キリコ・キュービィー: ギルガメス暦2326年7月7日生まれ。ギルガメス軍メルキア方面軍曹長。
- ロッチナ 2301-11-17、ココナ 2328-03-08、バニラ 2323-09-30、ル・シャッコ 2318-05-12、ブールーズ・ゴウト 2294-01-02（いずれもギルガメス暦生まれ）。

◎（2026-11-21に原文確認。詳細は [05_settings.md](05_settings.md)）
- 百年戦争はアストラギウス暦7113〜7213年（第3次銀河大戦の俗称）。
- ギルガメス暦元年は4871年、バララント暦元年は4153年。
- クエントの超古代文明は暦4000年頃に崩壊。

## 4. 主要用語

◎
- AT: アーマードトルーパー。作中の主力兵器で、単なる機械として描かれる。
- レッドショルダー: 第24メルキア方面軍戦略機甲兵団 特殊任務班X-1の通称。キリコは一時所属。
- PS（パーフェクトソルジャー）: ギルガメス軍が創ったPSの一人が**フィアナ**。秘密結社も第2のPSを創った。
  「PSの寿命は2年間」は、後のOVA『赫奕たる異端』制作時に付け加えられた設定。
- キリコは「生まれながらの孤高の異能者」で、ワイズマンの後継者とされる。

◎（2026-11-21に原文確認。詳細は [05_settings.md](05_settings.md)）
- 異能生存体: ペールゼンが命名した、生存確率が桁違いに高い個体。キリコが該当（公式KEYWORDS）。
  ※Wikipedia の用語節の見出しは「異能者」（クエント人の突然変異種）で、別の語。
- ヂヂリウム: 半液体化金属の半導体。PSの生命線。
- ワイズマン: クエントを追放された異能者が、原形質保存装置に意志を集合させた意識集合体。

## 5. この整理から見えたこと
- 最初の問いの補強: フィアナはTV本編側のPSで、ペールゼン・ファイルズより後の時間軸にいる。
  ペールゼン・ファイルズにはそもそも登場しない。
- 作品数が多く、OVA以降は暦も飛ぶ。時系列の把握が、各作品が「誰の物語か」を問う前提になる。
