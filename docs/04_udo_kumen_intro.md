# キリコとフィアナの出会い：ウド編〜クメン導入（TV第1〜19話）

> 出典は TheTVDB の日本語エピソード紹介（二次情報）。第1〜19話を読んだ。
> 紹介文が途中で切れている話は第8・14・18話。台詞・演出は本編で要確認。
> 確度: ◎=読んだ紹介文に明記、考=筆者の考察。
> これで第1〜52話の紹介文を一通り読んだことになる（切れた話を除く）。

## 1. 流れ（◎）

| 区間 | 話 | 内容 |
|---|---|---|
| 発端 | 1 | 百年戦争末期。キリコは突然の転属で小惑星リドの秘密作戦に参加し、カプセル内の裸の女性を見る。仲間に裏切られ宇宙へ放り出され、情報将校ロッチナに拘束される。拷問の前に脱走するが、体内には追跡用ビーコンがある |
| ウド | 2〜13 | 数か月後、ウドの街へ。ヂヂリウム採掘場、バトリング、ゴウト・バニラ・ココナとの出会い。治安警察署長イスクイ（リド襲撃を指揮した秘密結社の構成員）に追われる。ウドでキリコは「素体」と再会 |
| 別れ | 11〜13 | 素体（プロトワン）がキリコとの戦いを拒む。キリコは彼女を「フィアナ」と呼ぶ。ウド崩壊でフィアナと引き離される |
| クメン導入 | 14〜19 | 3か月後、内乱のクメンでEX-10に傭兵として入隊。青いAT（イプシロン）、フィアナとの再会、ロッチナからの素体奪還の依頼 |

## 2. キリコが軍に追われる理由（◎）

- 第1話: リドで、カプセル内の女性（素体）を見てしまった。仲間に裏切られて殺されかけ、ロッチナに「関与している」と確信された。
- 理由は、キリコ自身にも最初は分からない。第6話で彼はゴウトらに理由を聞かれても答えられない。
- 第10話: 周囲に彼がレッドショルダー出身であることが知られる（キリコにとって「忌まわしい過去」）。
- 第3・5・6話: 治安警察署長イスクイがリド襲撃を指揮した秘密結社の構成員で、キリコ抹殺を狙う。リド作戦の上官オリヤ大尉が、キリコを殺しに来る（第5話）。

## 3. 「フィアナ」という名の誕生（重要）

◎
- 第6〜7話: キリコはヂヂリウムを浴びる美女を見つけ、リドで見た素体だと気づく。「俺を覚えていないか」と問う。ロッチナは、素体がバッテンタインの「パーフェクトソルジャー計画」の中核だと聞かされて奪還を命じられる。
- 第11話: 治安警察のイスクイとボローが差し向けたプロトワンは、キリコとの戦いを拒む。「絶対服従のはずのPSが反抗した」と驚かれる。キリコは彼女に、コードネームは「名前じゃない」と告げ、敵ではないと悟る。
- 第12話: 彼女は、リド以来ずっとキリコを見ていたと語る。ATが破壊されたとき、キリコは「フィアナ！」と叫び、彼女はそれを自分の名前として受け止めて喜ぶ。直後、二人は引き離される。
- つまり、フィアナの名はPSにとって初めての「名前」。キリコが付けた。

考
- 第11話の「名前じゃない」と、第12話の「フィアナ」は対になる。コードネームは造られたものの記号だが、名前は人間として呼びかけられたもの。
- 03で見た、第22〜39話のフィアナの献身は、この「名を与えられた」ことが起点になっている。

## 4. フィアナが宮殿でキリコを救う（第14〜19話）

| 話 | 内容 |
|---|---|
| 14〜15 | クメンでキリコは、驚異的な反応速度の青いATにフィアナが乗っていると確信し、ハッチを開けて身をさらす。フィアナは彼に気づかない。キリコは疑念を持ち、対PS用のミッションディスクを作る |
| 17 | キリコが単身で神聖クメン王国の宮殿へ潜入。フィアナと再会する。イプシロンとの決闘で重傷を負うと、フィアナはとどめを刺すふりをして救う。夜の地下牢で、二人は気持ちを確かめ合う。フィアナはキリコを逃がして宮殿に残る |
| 18 | フィアナは、同じPSのイプシロンにだけ自分が手引きしたと告げる。イプシロンは責めない |
| 19 | ロッチナがキリコに素体奪還への協力を要請し、キリコは承諾する |

考
- 第17話の「とどめを刺すふり」が、第22話以降の秘密結社への反旗、第52話の最後の一撃（急所を外したと理解する）の原型にあたる。
- 第14〜15話は「キリコが誰か分からないフィアナ」と「それを疑うキリコ」で、フィアナが完全にキリコ側に寄ったのは第17話から。

## 5. 神の領域とのつながり（◎＋考）

- 第5話: 治安警察で投与された薬物がキリコに効かなかった。紹介文は「神の存在を信じないため」と書く（◎）。
- 考: 後にキリコが「神」を壊す結末（第52話）から見ると、最初から神を信じない人物として造形されている点は見落とせない。ただし、第5話のこの記述が本編のどの台詞に由来するかは未確認。
- 「異能」の語は第1〜40話の紹介文に一度も出ない。キリコの常人離れした力は、「驚異的な」「異常な」などの形容で描かれ、第48話で初めて名付けられる（◎）。

## 6. 訂正・追記（他の文書への影響）

- 第28話「運命」はウド編の総集編、第40話「仲間」はサンサ編の総集編、第20話「フィアナ」もウド編の総集編（日本語版Wikipedia各話リストの表で確認◎。TV52話のうち総集編3話に当たる）。第28話の紹介文が第1〜6話の筋と一致するのは、そのため。
- 02の冒頭で「第20話でキリコが『フィアナ』と呼ぶ」と読めるが、名付けは第12話（◎）。
