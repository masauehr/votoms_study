## 1. 物語の骨格（◎ TheTVDB第20話・第41〜52話）

| 段階 | 話 | 要点 |
|---|---|---|
| 出会い | 第20話「フィアナ」 | キリコは治安警察ビルで、小惑星リドの秘密作戦で出会った素体（PS）と再会。絆が生まれるが乱戦で引き裂かれる。クメンの船上でキリコが「フィアナ」と呼んで彼女を思う場面で終わる。 |
| クエント到着 | 第41〜42話 | 艦が墜落しキリコは惑星クエントへ。クエント人ル・シャッコと出会う。秘密結社は強攻策のアロン・グランと慎重論のキリィで割れる。 |
| 神の伝説 | 第43話「遺産」 | 村長テダヤは、キリコが「手を加えられた民」かもしれないと語る。長老メジが、3000年前に現れ追放された神の伝説を語る。 |
| 神の目覚め | 第44〜47話 | クエントの超科学が作動。AT・両艦隊が光や火球で次々消える。第47話、キリコ・ロッチナ・キリィの脳裏に「ワイズマン」と名乗る意志が呼びかける。 |
| 後継指名 | 第48話「後継者」 | 神殿に入れるのはキリコ一人。「神の声」が、キリコは生まれながらのPS・異能者でワイズマンの後継者だと告げ、キリコはこれを受け入れる。 |
| 神の領域へ | 第49〜51話 | キリコは「自ら神になる」と宣言し、シャッコを撃つ。連合軍の包囲を異能で突破し、最深部へ。ワイズマンは「全銀河を敵にまわして独力で辿り着く者が真の後継者」と語る。キリコは「全宇宙への復讐のため力が欲しい」と答える。フィアナだけが追い続ける。 |
| 神殺し | 第52話「流星」 | フィアナはキリコを止めようとするが、キリコは彼女から銃を奪う。キリコはATを捨てて徒歩で中枢へ登る。「神」の正体は過去の異能者の記憶・意識を保存した機械（原形質保存装置）で、キリコはその意思と記憶を破壊する。ロッチナが自爆装置を起動しクエントは消滅。1年後も戦争は再開。キリコはフィアナとコールドカプセルで旅立つ。 |

### 要点（◎）
- 後継者の指名（第48話）を受け入れたキリコが、最終話で神そのものを壊す。「神の領域に踏み込む」とは、神に近づくだけでなく、後継者として神の座を継ぐ道と、神を殺す道のどちらも選べる位置まで来ることだった。
- 第51話の「力が欲しい」という答えと、第52話の行動は逆向き。二つの間に何があったかは、紹介文だけでは読み切れない（下記の課題）。

## 2. フィアナの役割

◎
- 第20話: キリコが小惑星リドで出会った素体で、「すべての始まり」とされる。
- 第43〜49話: ロッチナ側に囚われたりキリコと再会したりを繰り返す。第47話で捕虜のゴウトたちと再会。
- 第50〜52話: キリコを諦めず追い続ける唯一の仲間。最終話で、キリコがロッチナの急所をわざと外したと理解し、一撃を加える。キリコと協力して神の記憶を壊す。

△
- 日本語版Wikipediaの記述として、フィアナはギルガメス軍が創ったPSの一人。秘密結社も第2のPS（イプシロン）を創った。

### キリコとフィアナの関係（読み取り）
- 二人の結びつきは「PSと異能者」という、造られた者同士の関係。
- フィアナは、キリコが神の道に傾いた時に引き戻す側。引き戻せなかった第50〜51話と、最後に再び呼応する第52話が対になる。これは筆者の考察で、紹介文の事実とは区別する。
