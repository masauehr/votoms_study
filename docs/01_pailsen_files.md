# ペールゼン・ファイルズ分析

## 結論（最初の問いへの答え）
**問い: ペールゼン・ファイルズはキリコとフィアナの物語か？**

**答え: いいえ。少なくともWikipedia英語版の記述上、フィアナ（Fyana）は本作に登場しない。**
中心はキリコ（Chirico Cuvie）と、彼を「異能生存体」「パーフェクトソルジャー」として観察・利用する軍上層部（ペールゼン、ウォッカム）の側。
フィアナを軸にした物語はTVシリーズ側にあたる。

## 根拠（Wikipedia英語版より）
- 位置づけ: 全12話のOVA（2007-10-26〜2008-08-22、Sunrise、監督 高橋良輔）。TVシリーズの数か月前。
- 骨子: ペールゼン大佐が軍法会議にかけられ、ウォッカムに尋問される。キリコが「異常生存者」かもしれないと供述。
- キリコは5人のAT部隊（バーコフ、ゴダン、ザキ、コチャック）に編成され、各戦場を転戦、最終話でモナド侵攻（Operation Z0-5）に至る。
- 登場人物一覧・各話あらすじに「Fyana／フィアナ」の名はない。

## 注意（検索要約の誤り）
検索エンジンの要約が「秘密結社」「イプシロン」「フィアナが教育係」などを本作の内容として述べたが、
これはTVシリーズ側の筋と混同しているとみられ、Wikipedia原文と矛盾するため**不採用**。
